# Web Component

Nova UI is a React and TypeScript component showcase for product websites and AI workspaces. It includes reusable page sections, prompt controls, action states, and a curated Keyline icon set.

## Run locally

Requires Node.js 20.19+ or 22.12+.

```sh
npm install
npm run dev
```

## Build

```sh
npm run build
npm run preview
```

## Included components

- `HeroSection` — responsive website hero section
- `PromptComposer` — AI prompt composer with idle, focused, and submitting states
- `ActionButton` and `IconButton` — shared action components with interaction states
- `KeylineIcon` — curated icons imported from the official Keyline Duotone React entry point

The icon style selection guide and component examples are available in the Figma file linked from the project brief.
